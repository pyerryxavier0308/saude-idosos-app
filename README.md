# Bem Cuidar — implementação do protótipo

Implementação front-end das telas do protótipo fornecido para a atividade de SCC0580 — Acessibilidade em Sistemas Computacionais.

## Como executar

Basta abrir `index.html` em um navegador moderno. Também é possível servir a pasta com um servidor simples:

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

## Arquivos

- `index.html` — estrutura base
- `styles.css` — estilos visuais
- `app.js` — telas, navegação e estados
- `PROMPT_USADO.txt` — prompt utilizado como referência para a implementação

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta para a raiz do repositório.
3. Em **Settings > Pages**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve e use o endereço publicado na entrega da atividade.

## Observação

Foram implementadas apenas as telas, estados e navegações representados no protótipo. Ações para as quais o protótipo não apresenta uma tela subsequente não criam novas telas ou conteúdos.
